# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability
We take the security and integrity of our codebase seriously. If you discover a vulnerability or abuse vector:
1. Please do **NOT** open a public issue.
2. Open a private GitHub Security Advisory or email the repository maintainers.
3. We will acknowledge and address the issue within 24-48 hours.
